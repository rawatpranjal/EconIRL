# Abstract MDP 1: sanity check

The simplest abstract problem: a small but non-trivial random MDP with an
action-dependent linear reward. It is deliberately easy enough that a correct
estimator must recover it, so it serves as the sanity check that the whole roster
works before we move to harder regimes. Every estimator that accepts the uniform
estimate interface is run here, and the page reports the exact recovered
parameters, policy distance from the true-parameter policy, and counterfactual
regret (Type A/B/C).

Environment: `random_mdp(num_states=8, num_actions=2, num_features=2,
branching=3, discount_factor=0.9, seed=0)`.
